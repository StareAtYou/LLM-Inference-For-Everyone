# 推理全过程与原理动图升级

用户反馈：当前流程图过于概括；每个模块/原理需要独立动态可视化，单请求/批请求需要完整、详细且简洁的数据流动演示。参考 https://poloclub.github.io/transformer-explainer/ 的节点展开与数值关联，而非复制 GPT-2 架构。沿用之前“直接实现”的授权、两款 Qwen 结构、A 阶段浏览器教学边界与无小练习。

## 体验

流程页重构为推理工作台，双入口“完整推理”“原理动图”。完整推理：模型、场景、单/批请求、槽位、粒度与采样参数 → 队列/批次 → 数据流画布 → 当前张量/缓存/输出。可播放、暂停、逐步、跳阶段、重置与调速；数据包沿输入、网络、状态、输出及反馈环路流动。请求使用固定颜色及 ID，点击请求查看自己的数据，完成后释放缓存；批处理有等待、补位、不同输入/输出长度。

网络同时包含 Tokenization、Embedding、RMSNorm、QKV、RoPE、Full Attention / Gated DeltaNet、输出投影、残差、Dense FFN / MoE、Final Norm、LM Head、采样、流式输出、反馈和结束。每层、每轮由同一事件轨迹计算；真实层数、层类型与张量逻辑形状来自已有预设，数值使用明确标注的小维度教学网络，不能冒充真实 Qwen 权重推理。

原理动图：覆盖现有全部 23 个知识主题，加 RMSNorm、QKV 投影、残差、LM Head、Softmax、注意力输出投影等内部运算。每个条目有独立、可操作的分步计算或机制图，输入 → 运算 → 输出、文字解释及有限的数值。专题页嵌入自己的动图；工作台可搜索、展开和返回全过程。

沿用纸色阅读/深色实验视觉；层级压缩为“现在处理谁、数据在哪、发生什么变化”。手机纵向布局，避免缩小桌面巨图；暗色画布有图例、键盘控件、读取文字、200%文本容纳，reduced-motion及离屏/后台暂停。

## 正确性与验收

轨迹可以回放，参数/模型/模式变更重置。按请求独立保存各层 KV 和递归状态，不跨请求混用；全注意力只增长已处理输入位置，最新采样 Token 尚未进入缓存；停止与释放可观察。批次形状清楚区分逻辑请求、padding/packed 与物理计算。示例网络的矩阵/归一化/采样为真实小数组计算，真实维度另列；所有指标为教学步骤或理论值。

测试覆盖每个请求结束、缓存隔离、批次补位、回放稳定、参数变化、不合法配置、算子数值与所有主题的动图覆盖；UI覆盖从输入至释放、单/批切换、节点深入/返回、控制时钟、窄屏/键盘/减弱动效。生产构建与截图复查完成后更新本地预览。
