# 大模型推理可视化学习网站：第一版设计

日期：2026-10-04（Asia/Shanghai）

状态：用户已批准设计；已纳入随后指定的两个 Qwen 模型示例。

工作名称：推理图谱 / Inference Atlas。仓库名称继续使用 LLM-Inference-For-Everyone。

## 1. 目标与已确认约束

建立一个以中文为主、保留英文术语和代码的交互式学习网站，帮助入门、深入、精通阶段的访问者理解大模型推理全过程、模型结构、优化机制与开源框架实现。

用户已确认：

- 第一版为 A：浏览器内的学习与机制模拟；以后逐步扩展到 B：真实模型服务与 GPU 实验。
- 第一版包含学习地图、推理全流程、模型结构探索、优化实验室、SGLang/vLLM 源码导览。
- 不包含小练习、测验、评分或答题任务。通过操作演示、参数对比、层级解释与回访巩固知识。
- 视觉方向为 A：技术出版物 × 交互实验室，浅色阅读界面配深色计算演示画布。
- 以 Awwwards、Webby Awards、FWA 获奖网站的完成度作为质量目标，检查排版、留白、视觉层级、色彩、动效、微交互、响应式与原创性。
- 浏览进度与收藏先保存在本地。浏览记录只代表访问过，不声称掌握程度。
- 实际模型结构示例使用 Qwen3.8-27B Dense 与 Qwen3.6-35B-A3B MoE，依据官方配置；第一版仍为教学模拟，实际权重执行留到 B。

第一版交付完整可运行的网站与可操作的核心专题，不把长期的“所有模块”目标解释为已经覆盖所有模型架构、硬件或框架特性。知识地图建立可扩展的分类，第一版范围之外的内容明确列入后续路线，不混入已交付主题。

## 2. 用户体验与内容组织

网站使用“一个请求如何成为回答”作为主线，以学习地图导航、专题页面解释、实验室验证机制、源码导览连接工程实现。

| 深度 | 读者需求 | 同一专题的实际变化 |
| --- | --- | --- |
| 入门 | 建立直觉，理解术语和数据流 | 简短解释、图示、具体输入输出、最少必要参数 |
| 深入 | 看懂计算和资源变化 | 张量形状、公式、假设、可调参数与对比结果 |
| 精通 | 联系系统约束与实现 | 内存布局、调度边界、适用条件、源码入口与实现差异 |

深度切换必须切换解释、标注和细节，不能只改变标签或配色。三个层级均可直接访问，不用测验解锁。复杂控制在入门层级使用合理默认值，深入层级展开。

专题统一组织为：核心问题 → 直观解释 → 可操作图形 → 数学/工程细节 → 框架关联 → 参考资料与相邻主题。用户可以从任何模块开始，不要求完成固定课程。

第一版采用六条主要路由；专题使用 `/learn/:topic`，学习深度使用 `?depth=beginner|advanced|expert`，框架模块使用 `?module=模块ID`。实验配置使用经过校验的查询参数，均可分享：

| 页面 | 核心内容 | 核心操作 |
| --- | --- | --- |
| 首页 `/` | 产品定位、原创推理过程图、三条学习路径、精选专题、框架入口 | 开始探索、选择学习深度、进入专题 |
| 学习地图 `/learn` | 按推理基础、模型计算、显存与调度、优化、框架组织的知识依赖 | 搜索、按层级/领域筛选、查看前置知识、收藏 |
| 推理流程 `/pipeline` | 输入、Tokenization、Embedding、Prefill、Decode、采样、输出 | 场景切换、播放、暂停、单步、重置、阶段跳转 |
| 模型结构 `/models` | Decoder-only Transformer 主干与 Attention/RoPE/MLP/GQA/MoE 对比 | 选择节点、展开细节、切换配置、观察形状变化 |
| 优化实验室 `/lab/:experiment` | KV Cache、分页缓存、连续批处理、量化、投机解码五个完整实验 | 参数调整、模式对比、单步演示、重置、保存配置链接 |
| 框架导览 `/frameworks/:framework` | vLLM 与 SGLang 的架构、请求流、调度、缓存、执行、输出模块 | 切换框架、选择模块、追踪关联、查看源码与原理 |

收藏、最近访问与继续阅读作为学习地图的视图，不额外增加账户系统。搜索覆盖已交付专题、同义英文术语与框架模块；空结果提供清除筛选和相关领域入口。不存在的主题/路由提供可返回的空状态。

## 3. 第一版内容边界

### 3.1 基础、流程与性能概念

完整解释 Token 与词/字的差别、Embedding、因果 Attention、Prefill 与 Decode 的区别、自回归生成、logits 与 softmax、temperature/top-k/top-p、停止条件，以及延迟/吞吐量/TTFT/每 Token 时间的区别。

推理流程采用小型教学场景，用户能查看提示 Token、生成 Token、当前阶段、张量形状和 KV 增长。Prefill 处理提示并产生用于第一个输出 Token 的 logits；之后 Decode 根据已生成 Token 继续执行，避免把首 Token 的时间归因到一个虚构的重复 Prefill。

第一版提供固定输入场景与解释过的教学 Token 序列；Token ID 标注为教学 ID，不冒充任何真实模型 tokenizer 输出。任意文本输入不伪装为真实分词服务。输出来自可复现的教学概率分布，不伪装为在线模型回答。

### 3.2 模型结构

展示 Embedding → 重复 Decoder Block → 最终归一化 → LM Head → 采样。Block 内包含归一化、Q/K/V 投影、RoPE、因果 Attention、输出投影、残差连接与 MLP。明确这是所选教学结构，归一化位置等并非所有 Transformer 的统一形式。

默认选择真实 Qwen 配置，另设明确标注的缩小教学结构以展开基础计算。真实预设的层数、维度与 head 配置只读；修改结构参数会进入“自定义教学配置”，不继续显示为原始模型。调整 head 数、KV head 数、序列长度会更新相关形状；GQA 对比解释 Query head 与 KV head 的共享关系；MoE 展示 Router、选中的专家、汇合及总参数/激活参数的区别。

Attention 提供可点击的因果矩阵与 Q/K/V 联动；RoPE 提供二维向量旋转示意；MLP 展示维度扩展与收缩。图形都配文字说明与图例。

### 3.2.1 Qwen 实际模型示例

| 配置 | Qwen3.8-27B Dense | Qwen3.6-35B-A3B MoE |
| --- | --- | --- |
| 官方仓库 revision | `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0` | `995ad96eacd98c81ed38be0c5b274b04031597b0` |
| Decoder 层数 / hidden size | 64 / 5120 | 40 / 2048 |
| Gated DeltaNet / full attention 层数 | 48 / 16 | 30 / 10 |
| 全注意力 Q heads / KV heads / head dimension | 24 / 4 / 256 | 16 / 2 / 256 |
| 前馈结构 | Dense，intermediate size 17408 | 256 个路由专家，每 Token 激活 8 个，另有 1 个共享专家；专家 intermediate size 512 |

两者的主干都重复“三个 Gated DeltaNet 层 + 一个全注意力层”。Dense 与 MoE 描述前馈结构，不能据此把 Dense 画成所有层都是标准全注意力。网络图展示完整层序列，点击层时联动对应模块、形状与缓存类型。

文本推理路径中，Vision Encoder 标记为模型包含但本演示未启用；MTP 作为结构说明，与简化投机解码实验关联，不冒充官方 MTP 执行。Gated DeltaNet 展示固定大小 recurrent state 与卷积状态的概念更新，教学数值不声称来自真实权重。

Qwen 缓存面板分别展示“全注意力 KV 分项”和“线性层状态”，不使用总层数套标准 KV 公式。第一版精确计算前者；后者显示配置维度、状态类别和不随 Token 数线性增长的含义，不给出未经运行时布局核对的总显存数字。网络形状以官方 `head_dim` 为准，不由 hidden size / head 数反推。

官方配置研究快照与来源校验信息保存在 `docs/references/models/`，实施时提取网站需要的配置字段，不下载模型权重：

### 3.3 五个优化实验

| 实验 | 可调输入 | 可观察结果 | 必须解释的边界 |
| --- | --- | --- | --- |
| KV Cache | 层数、KV heads、head dimension、序列长度、batch、数据字节数 | K/V 复用、逐步增长、理论占用与构成 | 缓存历史 K/V，不缓存历史所有计算结果；显存占用随上下文增长 |
| Paged Attention / 分页缓存 | block size、请求长度、请求完成与新请求到达 | 逻辑块→物理块、分配与释放、空闲块、尾块浪费 | 分页并非压缩；仍有尾块浪费；图示区分地址管理与注意力计算 |
| 连续批处理 | 预设请求流、到达间隔、生成长度、batch 上限、调度模式 | 静态与连续 batch 时间线、空闲槽位、完成顺序 | 同一工作负载、公开服务成本假设；模拟时钟单位不冒充实测毫秒 |
| 量化 | FP16/INT8/INT4、权重数组、量化范围 | scale、量化与反量化值、误差、权重存储估算 | 演示为指定的简化均匀量化；不把位宽比例等同端到端加速比例 |
| 投机解码 | 草稿长度、预设匹配场景、草稿/验证成本 | 草稿、验证、接受前缀、首次拒绝与修正、目标执行轮次 | 第一版为确定性 greedy 教学场景；不声称完成随机采样的分布保持算法 |

KV 估算公式为 `2 × layers × batch × tokens × kvHeads × headDim × bytesPerElement`，显示 bytes 与 GiB，并注明针对标准全注意力缓存；不直接套用于 MLA、滑动窗口或混合架构，也不计量化元数据、对齐及运行时开销。

批处理和投机解码的对比共享场景、成本模型与输入，结果来自实际模拟状态。速度比可能小于 1；不能预设“优化一定更快”。重置恢复明确初态，修改结构性参数时重新开始并给出提示。相同种子/输入得到相同模拟结果。

前缀复用作为缓存专题和 SGLang 框架导览的联动图形：展示共享前缀、Radix 树路径与 vLLM 块哈希的概念差异。FlashAttention、张量/流水线/数据/专家并行、chunked prefill、算子融合与 CUDA Graph 提供有实质解释的专题概览和资料入口；更完整的独立实验放在后续路线。

## 5. 视觉系统与交互

### 5.1 设计语言

暖白纸面、近黑正文、克制的紫色主色与少量青绿色状态色，配细线网格、编号、轴线和精细图例。色彩具有语义：阶段、数据流、缓存命中和选择态的映射保持一致，同时使用文字/形状，避免只靠颜色表达。

首页以有辨识度的大字排版和一幅原创请求流图为核心。图形直接表达 Token 经模型与缓存生成输出，避免无意义的装饰粒子、无功能仪表数字和模板化卡片堆叠。内容分区使用章节编号、横向编辑式布局、深浅画布节奏和充分留白。

学习页保持浅色阅读面，交互画布为深色，参数/解释为浅色。桌面可以并列，移动端按标题→图形→控制→解释排列。正文行长约 60–75 个英文字符等效宽度，中文保持舒适行长，字号不通过压缩来容纳复杂图表。

中文采用适合长文的无衬线字体，拉丁标题可用有辨识度的展示字体，代码与维度使用等宽字体。优先本地字体资源及系统回退，字体加载失败仍保持稳定可读布局。统一排版比例、间距尺度、边框、圆角和焦点样式。

### 5.2 动效与微交互

导航、按钮、收藏、节点选择有清晰的 hover/focus/active 状态。轻微过渡约 160–240ms，章节进入动效节制使用；计算动画以可读的阶段变化为核心，可暂停、单步和重置。

不劫持滚动，不强迫用户等待完整动画才能阅读。离屏和后台页面暂停持续动画。尊重 `prefers-reduced-motion`，关闭装饰动效并保留静态图形与单步操作。悬浮信息同时支持点击和键盘访问，复杂图形提供对应文字说明。

### 5.3 响应式与可访问性

至少检查 390px、768px、1440px 三种宽度，并补查 360px、1920px 边界。页面本身不能横向溢出；代码与大型时间线允许在明确的内部容器横向滚动。移动端导航可展开，核心操作不依赖 hover。

保证正文对比度达到 WCAG AA、控件有标签、焦点可见、语义标题层级连贯。播放状态有可理解的文本反馈，避免每帧向辅助技术播报。主要点击区域目标约 44px，放大文字后核心功能仍可使用。

## 6. 技术架构与未来扩展

在当前仓库实现可独立运行的前端，建议 React + TypeScript + Vite，使用路由组织页面；CSS design tokens 维护视觉系统，SVG/HTML 绘制可访问的结构图和矩阵。仅在确有性能需求时使用 Canvas。没有真实推理依赖，不下载模型权重、不要求 API Key。

模块分离：

| 模块 | 职责 | 依赖/接口 |
| --- | --- | --- |
| 内容目录 | 专题、层级文本、知识依赖、术语与来源 | 结构化静态数据，供路由/搜索/详情读取 |
| 模拟核心 | 纯函数计算、离散事件、可复现状态 | 接收参数/场景/种子，输出状态与观测值，不依赖 React |
| 图形组件 | 根据模拟状态绘图与反馈 | 只消费状态和事件，不内置另一套计算公式 |
| 页面与控制 | 路由、深度选择、播放与参数操作 | 调用模拟接口与内容目录 |
| 源码目录 | 版本、模块关系、引用与核对片段 | 与教学主题通过稳定 ID 关联 |
| 本地记录 | 收藏、最近访问、深度偏好 | 带版本的 localStorage，失败时退化为内存 |

数据流：用户修改参数 → 参数校验 → 模拟状态更新 → 图形/数字/解释同步更新。自动播放使用统一时钟，暂停后不得继续改变状态，结束后停止；避免多个组件分别维护不一致的 Token 计数或指标。

可分享配置只保存白名单参数与场景 ID，解析异常回退默认值并提示。浏览记录不包含任意私人提示词。localStorage 配额不足、不可用或旧数据格式损坏时，网站仍可正常使用。未知框架/实验、非法范围及不整除的 head 配置有可恢复的错误反馈。

为 B 预留轻量实验数据契约：参数、事件、观测值、来源类型（教学模拟/理论估算/实测）和时间单位。第一版实现模拟来源，未来后端可提供实测事件；现在不建设任务队列、GPU 连接、认证或计费。B 将在实际接入时单独设计，不让当前前端承担服务器凭据管理。

### 7.1 功能与内容

- 六个主要页面和已交付专题可访问、可分享、可刷新；导航与相关主题链接可用。
- 三个学习层级显示相应内容，搜索/筛选/收藏/最近访问具有真实行为。
- 推理流程、结构探索和五个优化实验均有可操作的完整闭环，播放、暂停、单步与重置一致。
- 两个 Qwen 预设显示正确的混合注意力层序列、前馈差异、官方 head dimension 与只读结构；MoE 的共享专家不遗漏；KV 分项只计全注意力层。
- 模拟核心验证有意义的不变量：KV 公式和单位正确；因果矩阵无未来信息；采样概率归一化和过滤范围正确；分页块不重复占用且释放后可复用；批处理不提前执行未到达请求；投机拒绝后的草稿不能被错误接受。
- 量化展示从实际量化/反量化结果计算误差；比较结果由模拟导出，边界参数没有 NaN/Infinity。
- 框架两套模块导览、版本标识、实际源码入口与引用完整；所有引用行号和片段经快照核对。
- 不出现小练习、成绩或“已掌握”推断，不使用虚构跑分、空按钮或假内容。

### 7.2 工程与视觉

- 类型检查、生产构建、针对模拟核心的必要测试及主要用户流程检查通过。
- 本地可启动，生产资源路径正确，无浏览器运行错误；控制台告警中的实际问题已处理。
- 用浏览器截图检查桌面、平板、移动端的所有主要页面与关键交互状态。逐项审查排版、留白、层级、色彩、动效、微交互、响应式、原创性。
- 修复发现的溢出、遮挡、阅读困难、图表失真、移动端不可操作、无反馈与动效干扰，改动后复查受影响页面。
- 检查键盘导航、减弱动效、字体失败回退与本地存储不可用场景。
- 页面/实验按需加载，避免全站启动时加载所有可视化；首次页面没有持续消耗资源的离屏动画。
- 完成后交付运行方式、内容/源码基线、验证结果、截图与明确的后续范围。奖项级作为设计目标，不宣称已获奖，也不把主观审美视为绝对无改进空间的证明。

## 8. 后续路线

先扩展专题与独立实验：FlashAttention、更多并行策略、chunked prefill、PD 分离、CUDA Graph、内核融合、不同缓存结构与多模态推理。随后设计 B：连接真实推理服务、流式事件、实测指标和实验记录；具备真实需求后再引入账户、云同步与算力管理。

第一版在页面资源加载完成后可以断网进行教学操作，联网只用于查看外部官方资料和源码；不包含离线重新加载所需的 PWA 安装与 Service Worker。当前交付为本地可运行项目与预览；公开部署在选定托管目标后执行。
