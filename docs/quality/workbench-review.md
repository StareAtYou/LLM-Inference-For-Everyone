本次范围：23 个已有主题及 6 个内部算子的独立动画，单请求与连续批请求的全过程数据流。保留第一版 A 的浏览器教学边界，没有测验或 GPU 后端。

## 内容与计算

- 官方只读模型拓扑：Qwen3.8-27B 64 层、Qwen3.6-35B-A3B 40 层，按真实 Full Attention / Gated DeltaNet 顺序逐层执行。
- 主轨迹为 H=4、Q 头2 / KV头1、head_dim2；固定教学权重、固定 Token ID。MoE 为 3 路由专家选2及1共享专家，与独立动图各自标注的示例区分。
- 同一组计算事件驱动张量、输出、概率、请求状态及物理块。各请求和各层历史独立；新输出在下轮处理后进入缓存，最后输出不再处理；结束释放 KV 页和线性状态。
- 批请求 R1/R2 在第0轮到达，R3 第1轮到达；并发1–3槽位，异长输出、等待补位、混合 Prefill / Decode，有专门的 mixed 标签。事件数与 tick 均非 GPU 耗时。
