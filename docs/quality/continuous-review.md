# 双模式演示复查 · 2026-10-05

用户目标：已有分段展示保留；新增整体连续动画，速度可控。关键帧来自连续动画的同一轨迹。

## 实现与边界

- `TimelineClock` 将不可变轨迹映射到连续时间；分段模式选取关键帧，连续模式通过 RAF 每次时间增量推进分数位置。
- 主流程的连续模式经过全部计算事件，包括概览省略的中间网络层与算子。关键帧粒度只控制分段模式的采样。0.25–16×速度、暂停、浮点拖动与定位层/轮次共用一个时钟。
- 29个原理各自提供双模式。连续场景保留整个机制图与真实数据形态，数据粒子沿连接持续移动；关键帧数值作为精确快照显示，不伪造插值激活。原理提供0.25–4×速度。
- 模式切换暂停但保留精确播放位置；调速保持位置；参数/模型更改停止并重置。观察本播放器元素，后台和离屏暂停，卸载清理时钟。
- 全过程动态网络层进度、请求颜色、数据传递与模块路径同一个分数位置驱动。张量局部预览按真实行列截取；末帧明确显示完成、缓存已释放。
- 教学动画时间有明确标注，不代表GPU实测时间。真实Qwen拓扑与小维度教学计算的边界延续上一版。

## 复查与修正

独立复查检查时钟、数学、参数边界和真实浏览器行为；检查74种默认/极端原理组合，未发现非有限结果或不规则矩阵。发现CUDA Graphs旧图有固定1.3秒循环，已使连续模式的快照图保持静止，由连续场景独占数据运动。修复动图库切回全过程时观察元素未重新绑定的问题；用回归复现离屏暂停。张量裁剪回归验证前2行/4列不会错误拼接原矩阵行。

实际查看1440px批请求连续场景、桌面QKV全通路图及390px连续场景；重点核对模式区分、路径、同源数据、速度/暂停、暗色对比与移动端控件。控件置于连续场景前方，播放不必滚过整张图。
