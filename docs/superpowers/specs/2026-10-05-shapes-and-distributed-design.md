# 张量形状与多 GPU 推理教学扩展

## 目标与既有约束

补齐输入、输出和中间计算对象的 shape、公式推导，以及 TP/DP/EP/PP/CP/SP 和通信原语。沿用中文、入门/深入/精通深度，无练习；所有新增机制可分段、连续演示、调速、暂停、重置。浏览器教学计算，明确区分模型逻辑维度、教学数值和真实硬件执行。保留现有连续动画、请求轨迹、GitHub Pages 子路径与 Hash 路由。

## 实现边界

1. shape 教学嵌入现有 TensorInspector 与 MechanismPlayer：每个阶段显示输入→运算→输出，轴图例、维度约束、数值代入、Prefill/Decode 与缓存区别。必须覆盖原有 29 机制；工程对象描述队列、块表、请求等真实结构，避免把它们伪装为密集张量。按模型配置显示 GQA 与混合注意力的不同维度；教学 H=4 与模型维度分栏。
2. 新增 /distributed 工作台，切分/通信两个视图。六种切分各有独立状态、对象分片、GPU 布局、通信边与推导。DP 推理副本无需常规梯度 AllReduce；SP 明确采用 Megatron 定义，区别完整注意力序列/CP；EP 说明组可与 attention DP/TP 共享，避免简单乘所有缩写。
3. 九种通信示例：AllReduce、AllGather、ReduceScatter、AllToAll、Broadcast、Reduce、Gather、Scatter、Send/Recv。可选 2/4 rank，使用可核对整数输入输出；区分拼接和归约、root 与非 root 缓冲区、分片归属，展示算子结果而非真实网络性能。连续动画沿持久路径移动带对象标签的数据，结果在到达后提交；分段使用同一时间轴关键帧。
4. 新主题纳入学习地图、检索与关联链接；导航和流程页可发现工作台；来源保存官方文档链接与核查日期。

## 验证与交付

纯计算测试验证 shape 维度、矩阵乘/切分/通信数值及边界；浏览器测试验证每个新模式、控制、URL、暂停/调速、手机与放大文本。完整单元与端到端回归、生产构建、Pages 模式、格式与脱敏扫描；独立代码审查。使用已有隔离 worktree；所有公开提交保持匿名元数据，既有用户授权允许推送 main 并自动部署。上线后验证新工作台链接。
