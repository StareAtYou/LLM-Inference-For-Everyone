## 功能与内容边界

- 三个深度是不同的解释和技术细节；最近浏览表示访问记录，收藏不表示掌握程度。没有小练习、评分、测验或假进度。
- 两个 Qwen 预设读取保存的官方 config.json，真实层数与维度只读；修改 hidden size 会进入自定义教学模式。Token ID、激活、候选分布、输出和专家路由均标明教学数据。
- 全注意力 KV 分项公式不包含线性层循环/卷积状态、权重、激活或其他运行时开销，不能作为完整 GPU 显存。
- 分页分配先验证容量，再提交状态；极大有效 URL 参数与滑块一致，资源不足不产生部分分配。5 / 8 / 13 / 32 Token 预设便于探索小型块池。
- 连续批处理比较同一到达序列、Decode 单位时钟和容量；忽略 Prefill、网络、排队实现等成本，结果不是框架基准。
- INT4 / INT8 为小数组对称权重量化，标明尺度/元数据不计入权重载荷；零权重结果有限。
- 投机解码限定贪心目标序列，展示接受/拒绝/目标修正，不声称覆盖随机采样分布保持算法。
- vLLM / SGLang 为固定 commit 的源码导览，调用、消息、数据边分别标注，折叠中间层明确说明。短源码段保存路径、符号、行号、许可证与源文件哈希，不声称复现完整调用栈或验证生产模型支持。
- 论文和官方资料链接逐项复查；纠正批处理引用，分别使用 Orca 的 USENIX 页面与 SARATHI 原始论文。混合结构来自模型配置，概念说明与来源分开。

## 验证
